
------------- SAMPLING_80_20.py -------------
Цей код для того, щоб поділити всі зображення на тестову та навчальні вибірки у певному процентому співвідношені.

1. Вх. дані:
- датасет
- всі зображення на початку розміщенні у папці train, а у ній - кожен клас у своїй папці
- повністю порожня папка val (для створення тестової вибірки)
- percent = 0.2, це відсоток зображень, що будуть переміщені у папку val для валідації 

2. Що робить код: у циклі копіює назву всіх папок класів із папки train у папку val і переміщує (percent*100%) для створення тестової вибірки



-------------- test_example_5.py ---------------
Цей код ШНМ АлексНет для визначення 38 класів.

1. Весь код розміщено у одній функції run(), яка викликається через main десь в самому кінці коду. Це було так зроблено, щоб запрацювало те "розпаралелення" опрацювання зображень (num_workers=4) у завантажувачах даних (dataloaders_dict). Я читала, що весь отак код треба виносити в одну функцію лише у Windows, у Linux такої проблеми нема.
Інакше у Windows воно працюватиме лише для num_workers=0

2. batch_size = 64 - розмір партії зображень, які обробляються за одну ітерацію. 
К-сть ітерацій в одній епосі = (к-сть всіх зображень у датасеті / batch_size).

3. num_epochs = 13 - к-сть епох. 
До речі, у ініціалізації функції 
def train_model(..., num_epochs=25, ...) 
у параметрах задано 25, але вже при виклику функції ми передаємо те число, що було задано. У нашому випадку, це 13.

4. Після кожної епохи зберігається модель і зберігається чекпоінт.

5. feature_extract = True - це параметр, який визначає, який тип transfer learning ми будемо використовувати.
False->Finetuting, True->Feature extraction
- Finetuning. Тут змінються при навчанні лише останній шар
- Feature extraction. Тут при навчанні змінються декілька шарів. Я так розумію, цей тип навчання буде давати точніші результати, бо більше шарів перенавчається.

6. Після закінчення навчання зберігається, я так розумію найкраща модель, яка була отримана за всі епохи (тобто, це може бути не остання, а, наприклад, передостання тощо)
