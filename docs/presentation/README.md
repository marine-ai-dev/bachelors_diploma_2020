# Defense Presentation

**Title:** Intelligent Application for Identifying Diseases of Agricultural
Plants Based on Deep Learning
**Author:** Maryna Antonevych — Taras Shevchenko National University of Kyiv, 2020

## What's here

- [`english/presentation-en.md`](english/presentation-en.md) — a full,
  natural-English adaptation of the original defense presentation content
  (not a literal machine translation; all technical claims and figures are
  preserved exactly as in the original).
- `original/` — the original Ukrainian `.pptx` is not committed to this
  repository (it is ~22.6 MB and exceeded the size this restoration's
  Google Drive access tool could fetch). It remains archived in the
  author's Google Drive; a note is left here rather than a broken file.
- `slides/` — reserved for slide-by-slide screenshot images. Not populated
  in this restoration pass (see note below).

## Note on slide images

Rendering the original `.pptx` into per-slide PNGs requires either
PowerPoint/LibreOffice conversion or downloading the full binary, neither of
which was available/practical in this automated restoration pass. The full
textual content of every slide is preserved faithfully in
[`english/presentation-en.md`](english/presentation-en.md) instead.

## Excluded from this repository

Several files found alongside the presentation in the original source folder
were **not** included, because they are not this author's own work or are
personal/private material:

- Presentations belonging to other students (different authors entirely)
- Video recordings of the live defense session and grade announcements
- A generic, unrelated stock PowerPoint template
